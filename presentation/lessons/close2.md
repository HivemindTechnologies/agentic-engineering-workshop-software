# 💡 Close 2

**The Close.** Skipping approvals without a boundary leaves only your attention as defence. Inside a boundary, it only skips the click.
Four conditions tell which of the two you are doing. Then each team answers three questions in writing.

----

## Skipping approvals, honestly

- Without a boundary, the last line of defence is your attention at prompt twenty
- Claude Code's own sandbox bounds Bash, not the file tools
- So `--dangerously-skip-permissions` removes the only check on the file tools
- Inside the `nono` profile, the flag skips the click, not the wall

----

## Four conditions

1. **In version control**: anything destroyed is one `git` command away
2. **No credential worth stealing is reachable**: keys live outside the box
3. **The network is narrow**: ports at the kernel, hosts behind the proxy
4. **You could afford to lose what it reaches**: name it and how you get it back

With all four, an unattended run, gated and reviewed as a diff, is ordinary.

----

## Three questions, in writing

- **What do we still read line by line?** Name cases: credentials, money, a schema
- **How do we get there?** One team goes first and reports what the setup caught
- **Who owns the `AGENTS.md` files and skills?** Owner, version, deprecation path
