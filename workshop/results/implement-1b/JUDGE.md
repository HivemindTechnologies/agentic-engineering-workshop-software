# Judge

You judge the result trees of this lesson. Each tree is its own `## <stamp>` section, with the spec the run wrote under it — judge only that copy. A `# Given to the participant` section, if present, is the starting material the participant saw before the lesson ran, not a result; do not quote from it. The heading list of the spec is the outline.

The participant is told two things: mark the milestone done, and commit. Judge only the first. A commit needs a git history, and this run has none. That does not decide the verdict.

1. M1 of the spec is `(Status: ✅ DONE)`. `(Status: IMPLEMENTED)` fails this claim. `(Status: PENDING)` fails this claim.

The verdict is pass only when that claim passes. The claim quotes one line from the spec and names the tree.

End your answer with one line, alone, either:

```
verdict: pass
```
