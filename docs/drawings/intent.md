## Ideas

Follow-up to `sprouts`: this is what happens when spec and code are
disconnected. “Why write a spec — can’t I just chat and battle through?” Sure —
then someone is being eaten by the codebase, screaming, and everyone asks *why
is it like this?* with no recoverable intent, shrugs, and even *is this
normal?* Keep the specification next to the code so both coexist and those
question marks never have to appear.

This happens every day even without AI. Humans already share country, education,
and lived experience that models lack — they learned to talk, not to walk or
manipulate objects in our world, so they don’t understand our problems. We
already face the communication gap without AI; putting the spec beside the
code is how you keep that gap from opening in the first place.
