## Ideas

Even twins — same genetics, same upbringing, often the same education — can sit
in the same room, face the same situation, and behave completely differently.
Shared values and shared history do not guarantee mutual understanding. Two
people talking are already likely to miss each other; communication is hard.

Throwing in a machine that does not share those values does not make this
simpler. It makes it harder.
