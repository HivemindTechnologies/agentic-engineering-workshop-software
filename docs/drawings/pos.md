## Ideas

SDLC roles bring different expertise; a great product needs that expertise
shared. AI can mediate across fields and carry forward patterns from many past
developers and product owners — but only if specs are not a minefield: everyone
needs access to specs that live next to the code, not only in Jira, maintained
with the code and reflected back.

Practical loop: a product owner drafts on their tooling; changes sync into the
codebase; codebase changes sync back to Jira (or the tool of choice) so both
sides stay aligned. Everyone can then create or refine specs the same way, with
AI helping. Structured, code-like specs scale for AI review; unstructured
tickets do not.

Someone who is not deep in code can still describe what is needed; AI helps
turn that into a crisp, minimal, readable specification — a document teammates
can exchange and follow. Chat-only battles leave no durable “why.” Specs are
central documentation and communication today.
