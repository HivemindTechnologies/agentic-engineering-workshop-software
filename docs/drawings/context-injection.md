## Ideas

The brain is pre-trained: infrastructure, railroads, common tools — baked into
the weights, static, not going away. Whatever you pour into the session, that
training does not disappear. Against that, only a tiny short-lived speck is
reserved for what *you* care about: the context window.

Everything company-specific has to compete for that limited space: standards,
processes, skills that describe how to do a task, the chat itself, the task,
domain knowledge, internal tools, business needs. The model does not know any
of that until you tell it.

Load paths differ: e.g. in Claude, `AGENTS.md` is always loaded and stays for
the session; skills load on demand. Both still spend the same scarce budget.
